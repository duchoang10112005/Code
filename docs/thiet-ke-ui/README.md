# Thiết kế giao diện (UI)

Bản thiết kế các màn hình của hệ thống, dạng HTML tĩnh (`*.dc.html`). Đây là nguồn để chuyển thành template Django trong `templates/`.

- Mở trực tiếp file `.dc.html` bằng trình duyệt để xem (cần giữ `ui.css`, `icons.css`, `support.js` cùng thư mục).
- `anh-xem-nhanh/`: ảnh chụp từng màn hình để xem nhanh.
- 3 vai trò: Gia sư, Nhân viên tuyển sinh, Admin.
- Một số màn hình có hai bản (`v2` là bản mới hơn).
